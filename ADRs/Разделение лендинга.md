### Контекст

Сейчас в архитектуре проекта видно строгое разделение двух независимых контуров:
- Процесса редактирования (редактирование лендингов).
- Режима эксплуатации (просмотр лендингов).

Представлять все в виде единой сущности довольно проблематично, так как выбранное представление может быть неоптимальным для одного из контуров.

### Решение

Предлагается разделить лендинг на две сущности:

- Черновик - подходит для процесса редактирования. Может быть представлен в виде структурированного JSON-объекта, содержащего всю логику, привязки данных и мета-информацию, необходимую рендереру для построения страницы.

- Публикация - представлена в виде статических файлов (HTML / CSS / JS / медиа). Больше подходит для режима эксплуатации, которая подразумевает просмотр лендингов через браузер.
