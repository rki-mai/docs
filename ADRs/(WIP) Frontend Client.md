# (WIP) Frontend Client

> Эта страничка находится еще в разработке и будет уточнена при детальном проектировании сервиса.

Одностраниченое приложение, выполняет роль точки входа для запуска и работы конструктора лендингов.

## Основные понятия и определения

- **Холст (Canvas)** - центральная рабочая область редактора, где визуально отображается структура
  лендинга в режиме реального времени. Позволяет пользователю видеть изменения сразу после
  применения настроек к компонентам.

- **Предпросмотр (Preview)** - режим симуляции опубликованной страницы внутри среды разработки.
  Позволяет проверить адаптивность, работу интерактивных элементов и логику форм без создания реальной публикации.

- **Шаблон (Template)** - предустановленный набор компонентов и их начальной конфигурации,
  служащий основой для быстрого создания нового лендинга.

- **Стили (Styles)** - набор правил оформления (шрифты, цвета, отступы), применяемых ко всему проекту
  или конкретному его элементу, обеспечивающий восприятие лендинга.

## Offline-First

Для того, чтобы не нагружать backend-часть частыми запросами, frontend client будет придерживаться
парадигмы [Offline-First](https://rxdb.info/offline-first.html):

- Сначала данные сохраняются в локальном хранилище браузера. Можно использовать стратегию
  [debounce](https://doka.guide/js/debounce/).

- По наступлении какого-то события отправляет запрос в backend для синхронизации состояния.
