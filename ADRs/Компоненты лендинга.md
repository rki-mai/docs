# Компоненты лендинга

## Контекст

Для того, чтобы бэкенд- и фронтенд-части системы работали согласованно, необходимо зафиксировать
минимальную модель компонентов и их параметров. Отсутствие единого описания модели приводит
к риску рассинхронизации интерфейсов и несовместимости данных между частями системы.

## Решение

Предлагается ввести следующий минимальный набор компонентов, которые должна поддерживать система.

### 1. Заголовок

Отображает текстовый заголовок с заданным уровнем вложенности.

![](./.images/image-1.png)

### Параметры

| **Название**      | **Тип**               |
| ----------------- | --------------------- |
| Уровень заголовка | Число в диапазоне 1-3 |
| Текст заголовка   | Строка                |

### 2. Callout

Блок для выделения важной информации или поясняющего текста.

![](./.images/image-2.png)

### Параметры

| **Название**    | **Тип** |
| --------------- | ------  |
| Текст callout-а | Строка  |

> [!INFO]
> Текст callout-а не поддерживает форматирование (выделение жирным и прочее)

### 3. Кнопка с ссылкой

Интерактивный элемент для навигации по внешней ссылке.

![](./.images/image-3.png)

### Параметры

| **Название** | **Тип** |
| ------------ | ------- |
| Текст кнопки | Строка  |
| Ссылка       | Строка  |

### 4. Изображение

Отображение графического контента с настройкой масштаба.

![](./.images/image-4.png)

### Параметры

| **Название**        | **Тип**             |
| ------------------- | ------------------- |
| Контент изображения | Байты               |
| Масштаб             | Целое число (0-100) |
